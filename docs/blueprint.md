# **App Name**: LD Flow AI

## Core Features:

- Real-time Flow Layout: Provides a grid-style layout tailored for Lincoln-Douglas debate, supporting AC, NC/NR, 1AR, 2NR, and 2AR structures.
- Custom Shorthand Expansion: Expands LD shorthand automatically (e.g., V → Value), supports custom dictionaries, and allows real-time modifications.
- AI Argument Detection: Detects arguments by comparing flows across speeches, identifies dropped arguments, and highlights key clash points. Uses a reasoning tool to check if a given piece of evidence would be applicable when it formulates its decision on the arguments presented in the speech.
- Strategic Tagging: Enables users to tag points as offense, defense, or round voters for easy identification and summary.
- AI Speech Summaries: Generates automatic speech summaries, including outlines of main points (Value, VC, contentions), tracking dropped Aff points, and identifying winning arguments and strategic voters.
- Export Options: Supports exporting flows to PDF, DOCX, or text format, with options to include either shorthand or fully expanded arguments.
- Hotkeys and Autocomplete: Optimizes real-time note-taking with hotkeys for common functions and autocomplete for shorthand entries.

## Style Guidelines:

- Primary color: Dark gray (#212121) to provide a comfortable viewing experience in low-light conditions.
- Background color: Black (#000000) for maximum contrast and reduced eye strain.
- Accent color: Teal (#00BCD4) to provide highlights, call attention to important UI elements, and support quick orientation without distracting from content.
- Body text: 'PT Sans', a humanist sans-serif for a clean and readable experience; use also for headlines.
- Code font: 'Source Code Pro' for displaying shorthand commands or representing code snippets.
- Minimalist icons for key actions like tagging, exporting, and summarizing, emphasizing speed and efficiency. Use light colors for visibility against the dark background.
- Clean, grid-based layout for structuring flows logically, optimized for real-time entry and minimal distractions.
- Subtle animations for expanding shorthand and highlighting key arguments, providing immediate feedback without disrupting workflow. Use light colors for visibility against the dark background.
